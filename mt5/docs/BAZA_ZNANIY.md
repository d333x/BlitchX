# База знаний ProfitScalper — графики, свечи, прогноз, успех

Эта база встроена в робота (`Include/ChartKnowledge.mqh`) и используется в режиме `DIR_AUTO` для оценки направления. Ниже — сжатое «знание», на котором строится оценка.

---

## 1. Что такое японская свеча

Каждая свеча = движение цены за период (M1…MN):

| Элемент | Смысл |
|---|---|
| **Open (O)** | Цена открытия периода |
| **High (H)** | Максимум |
| **Low (L)** | Минимум |
| **Close (C)** | Цена закрытия |
| **Тело** | \|Close − Open\| |
| **Верхняя тень** | High − max(Open, Close) |
| **Нижняя тень** | min(Open, Close) − Low |
| **Диапазон** | High − Low |

### Обозначение направления

- **Бычья (bull)** — Close > Open → зелёная/белая. Покупатели закрыли период выше.
- **Медвежья (bear)** — Close < Open → красная/чёрная. Продавцы продавили закрытие вниз.
- **Додж (Doji)** — тело очень маленькое (O ≈ C). Нейтральность / нерешительность.

Правило робота: сила свечи = отношение тела к диапазону + положение закрытия внутри диапазона.

---

## 2. Как читать «движение» (price action)

1. **Импульс** — крупное тело, короткие тени против движения → рынок уверен в сторону закрытия.
2. **Откат** — небольшие свечи против тренда после импульса → часто место для входа по тренду.
3. **Поглощение (Engulfing)** — новая свеча полностью перекрывает тело предыдущей противоположного цвета.
4. **Пин-бар / молот / падающая звезда** — длинная тень против стороны входа, маленькое тело у одного края → возможен разворот.
5. **Структура:**
   - Бычий тренд: Higher High (HH) + Higher Low (HL)
   - Медвежий: Lower High (LH) + Lower Low (LL)
   - Флэт: примерно одинаковые пики/впадины

Робот смотрит закрытые свечи `[1]` и `[2]` (не текущую `[0]`, чтобы не перерисовывать сигнал).

## 3. Паттерны, которые робот умеет считать

### Бычий bias (+)

| Паттерн | Признак | Действие |
|---|---|---|
| Hammer / Pin up | длинная нижняя тень, тело сверху | склон к BUY |
| Bullish Engulfing | медвежья → бычья поглощает тело | BUY |
| Morning Star (упрощ.) | медвежья → маленькая → бычья | BUY |
| Three White Soldiers (упрощ.) | 3 бычьих закрытия выше | сильный BUY |
| HL + HH | структура роста | BUY по тренду |
| Закрытие у High | импульс вверх | BUY |

### Медвежий bias (−)

| Паттерн | Признак | Действие |
|---|---|---|
| Shooting Star / Pin down | длинная верхняя тень, тело снизу | склон к SELL |
| Bearish Engulfing | бычья → медвежья поглощает | SELL |
| Evening Star (упрощ.) | бычья → маленькая → медвежья | SELL |
| Three Black Crows (упрощ.) | 3 медвежьих закрытия ниже | сильный SELL |
| LH + LL | структура падения | SELL по тренду |
| Закрытие у Low | импульс вниз | SELL |

### Нейтраль / осторожность

- Doji после длинного хода → снизить агрессию / ждать подтверждения.
- Inside Bar (свеча внутри предыдущей) → сжатие, часто пробой.
- Очень большой спред / ATR → хуже скальп-фарм.

## 4. Как робот «предугадывает» сторону

Никакого магического предсказания. Оценка = сумма голосов:

```
score = EMA-тренд + свечные паттерны + структура HH/HL + импульс закрытия
BUY  если score > +порог
SELL если score < −порог
иначе — последняя прибыльная/последняя сторона (farm continuity)
```

Приоритет:

1. Фиксированное направление (`DIR_BUY` / `DIR_SELL`) — если задано вручную.
2. Согласованный голосовой score из базы знаний.
3. Иначе EMA H1 тренд.
4. Иначе последняя сторона корзины (чтобы фарм не «флипал» без причины).

## 5. Что делать для успеха (правила эксплуатации)

### А. Правила рынка (реальность)

- Спред съедает мелкий плюс — на золоте порог фиксации выше (`GoldMinProfit`).
- Прогноз ≠ гарантия. Паттерн повышает вероятность, не даёт 100%.
- Новости/гэпы ломают тени и стопы — в такие минуты фарм опасен.

### Б. Правила робота (как задумано)

1. **Фарм-цикл:** открыл корзину → зафиксировал плюс → cooldown → снова.
2. **Не держать минус «из веры»** — либо lock по profit, либо SL/BE/trail.
3. **Раздельные символы:** forex и золото независимы (до 5 позиций каждый).
4. **Дневной стоп** (`MaxLossMoney` / `MaxLossPercent`) — не отыгрывать ярость.
5. **Algo Trading ON**, VPS 24/7 если нужен непрерывный фарм.

### В. Практический чеклист успеха

- [ ] Демо → форвард → только потом реал  
- [ ] Спред нормальный для символа (золото шире)  
- [ ] Не ставить лот «на удачу» — 0.10 демо ≠ риск на всём депозите  
- [ ] Смотреть журнал: `LOCK`, `FARM`, score reason  
- [ ] Если день в глубоком минусе — пауза, не отключать защиту  
- [ ] На реверсе структуры (слом HH/HL) доверять новому bias, не старой стороне  

### Г. Чего робот сознательно не делает

- Не читает новости/календарь.
- Не гарантирует прибыль.
- Не подставляет «веры» вместо риска: стоп и дневной лимит важнее любого паттерна.

## 6. Таймфреймы в голове робота

| TF | Роль |
|---|---|
| **H1 (TrendTF)** | Основной тренд EMA fast/slow |
| **M15 (SignalTF)** | ATR, свечные паттерны, структура |
| График навешивания | Только «якорь»; торговля идёт по списку символов |

Золото (`XAU*`) использует ту же логику, но с отдельным лотом и порогом фиксации.

## 7. Краткая шпаргалка «куда пойдёт»

| Видишь на графике | Вероятный bias | Действие робота |
|---|---|---|
| Бычье поглощение + EMA вверх | вверх | BUY корзина |
| Пин вниз / shooting star + EMA вниз | вниз | SELL корзина |
| 3 солдата против EMA | конфликт | ждёт score / last dir |
| Флэт + doji | нет края | last dir / default, осторожный фарм |
| Импульс + закрытие у экстремума | продолжение | вход по импульсу |

**Успех = правильная сторона + быстрая фиксация плюса + жёсткий дневной стоп, а не «идеальный» прогноз.**
