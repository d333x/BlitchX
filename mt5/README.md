# ProfitScalper v3.70 — один график + предикт большой прибыли

Накидываешь EA **только туда, где нужно**. По умолчанию торгует **только символ графика** (`AlsoSymbols` пустой).

## Предикт

На M5/M15/H1 считает, пойдёт рынок **вверх (BUY)** или **вниз (SELL)**.

| Сила предикта | Что делает |
|---|---|
| Слабый (`gap < StrongScoreGap`) | Быстрый lock от `$MinProfitMoney` (0.50), TP = 1.5R |
| Сильный (`gap ≥ 6`) | Цель **большой прибыли** `$BigProfitMoney` (5.00), TP = **3R**, trailing |

## Установка на золото

1. Открыть график **XAUUSD** (H1)
2. Перетащить `ProfitScalper` на этот график
3. Algo Trading ON
4. Не ставить на EURUSD/другие, если не нужно

Файлы: `Experts/ProfitScalper.ex5` + `Include/ChartKnowledge.mqh`

## Важно

Предикт повышает вероятность стороны и размер цели — **не гарантирует** прибыль.
