# ProfitScalper — робот для MetaTrader 5

Скальпер, который:

1. Открывает сделку (Buy или Sell)
2. Следит за прибылью на каждом тике
3. Как только прибыль достигла заданного порога — сразу закрывает позицию
4. Снова открывает новую сделку
5. Крутит цикл, пока вы не снимите советника с графика

## Установка

1. Откройте MetaTrader 5 → **Файл → Открыть каталог данных**
2. Скопируйте `mt5/Experts/ProfitScalper.mq5` в папку `MQL5/Experts/`
3. В MetaEditor нажмите **Compile** (F7)
4. В MT5 обновите «Навигатор» (правый клик → Обновить)
5. Перетащите **ProfitScalper** на нужный график
6. Включите **Algo Trading** (кнопка в панели инструментов)

## Параметры

| Параметр | Описание | Рекомендация |
|---|---|---|
| **Направление** | Buy / Sell / Авто | Авто — по последнему движению цены |
| **Лот** | Объём сделки | Начните с `0.01` |
| **Режим фиксации** | Деньги ($) или пункты | `$` удобнее на большинстве символов |
| **Мин. прибыль** | Порог закрытия | `$0.10` или `5–10` пунктов |
| **Пауза (мс)** | Пауза между закрытием и новым входом | `200–500` |
| **Stop Loss** | Опциональная защита от просадки | Включите на реальном счёте |
| **Лимит убытка за день** | Останавливает торговлю при дневном минусе | Полезно для контроля риска |

## Как работает логика

```
нет позиции → открыть Buy/Sell
есть позиция → если прибыль >= MinProfit → закрыть
после закрытия → короткая пауза → снова открыть
... бесконечно, пока EA запущен
```

В режиме **Авто** направление выбирается по последнему движению Bid/Ask:
- цена пошла вверх → Buy
- цена пошла вниз → Sell

## Важно

- Для закрытия «в плюс» цена должна пройти **больше спреда**. Если `MinProfit` слишком маленький, сделка может долго висеть в минусе из‑за спреда.
- На центовых счетах и высоковолатильных парах (XAUUSD, US30 и т.п.) подберите `MinProfit` и лот осторожно.
- Это агрессивный скальпер без сложного фильтра входа — на демо сначала проверьте поведение.

## Остановка

Снимите советник с графика или выключите **Algo Trading** — цикл остановится. Открытая позиция при этом не закроется автоматически (закройте вручную, если нужно).
