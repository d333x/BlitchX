# ProfitScalper v2 — робот для MetaTrader 5

Скальпер с **анализом рынка** перед входом:

1. Считает score для **Buy** и **Sell** (тренд, EMA, RSI, свеча, сессия)
2. Входит только если одно направление **явно сильнее**
3. Фильтрует плохой спред, слабую/бешеную волатильность и «тихие» часы
4. Закрывает при достижении прибыли (и опционально при развороте анализа)
5. Повторяет цикл, пока советник не остановлен

## Установка

1. MT5 → **Файл → Открыть каталог данных**
2. Скопировать `mt5/Experts/ProfitScalper.mq5` в `MQL5/Experts/`
3. MetaEditor → **Compile (F7)**
4. Перетащить на график, включить **Algo Trading**

## Как выбирается Buy / Sell

| Фактор | Buy | Sell |
|---|---|---|
| Тренд (M15 EMA) | быстрый EMA выше медленного | наоборот |
| Импульс тренда | EMA растёт | EMA падает |
| Сигнал (M5 EMA) | бычий | медвежий |
| Моментум / кросс | ускорение вверх | ускорение вниз |
| RSI | нормальная зона / oversold в аптренде | нормальная зона / overbought в даунтренде |
| Свеча | бычья импульсная | медвежья импульсная |
| Сессия | Лондон / NY / оверлап | то же |
| Цена vs EMA | выше обеих EMA | ниже обеих EMA |

Вход, если score ≥ `MinScore` и отрыв от противоположного ≥ `ScoreGap`.

## Оптимальные сессии

По умолчанию: **SESSION_BEST** = Лондон + Нью-Йорк + их пересечение (лучшая ликвидность).

Часы задаются по **серверному времени брокера** — при необходимости подстрой `London/NY/Asia` start/end.

## Важные параметры

- `MinScore` (по умолчанию 4) — чем выше, тем реже и строже входы
- `ScoreGap` (2) — насколько Buy должен быть сильнее Sell
- `MaxSpread` — не входить при широком спреде
- `ATR` min/max — отсечь «мертвый» и хаотичный рынок
- `Stop Loss` + дневной лимит убытка — включены по умолчанию
- `CloseOnReverse` — выход, если анализ развернулся против позиции

## Запуск / стоп

- **Старт:** EA на график + Algo Trading ON  
- **Стоп:** удалить EA с графика или выключить Algo Trading  
- Открытая сделка при стопе **сама не закроется**

## Важно

Убытки всё ещё возможны: это не гарантия прибыли, а более аккуратный вход. Сначала демо. На iOS советники **не запускаются** — только ПК/VPS.
