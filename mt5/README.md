# ProfitScalper v3 — Profit Engine

Робот перестроен под **заработок за счёт матожидания**, а не фиксации копеечного плюса.

## Идея

Старая схема «открыл → сразу закрыл при +$0.10» почти всегда проигрывает спреду.  
v3 делает наоборот:

1. Входит **только в сильный тренд** (EMA H1 + M15, ADX, RSI, свеча, откат, сессия)
2. Рискует **фиксированный % депозита** на сделку
3. Ставит **TP = 2× риск (R)** — цель больше стопа
4. Переносит SL в **безубыток**, затем **ведёт трейлинг**
5. Режет день при достижении лимита убытка

Это правильная конструкция для попытки заработка. **Гарантии прибыли нет** — рынок, брокер и проскальзывание могут дать минус. Сначала демо.

## Установка

1. Скопировать `mt5/Experts/ProfitScalper.mq5` → `MQL5/Experts/`
2. Compile (F7) в MetaEditor
3. На график + **Algo Trading ON**
4. Подстроить часы сессий под **время сервера брокера**

## Ключевые настройки

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `LotMode` | Risk % | Лот считается от риска |
| `RiskPercent` | 1% | Риск одной сделки |
| `RewardRisk` | 2.0 | Цель в 2 раза больше стопа |
| `MinADX` | 22 | Не торгуем слабый рынок |
| `SessionMode` | BEST | Лондон / NY |
| `MaxTradesDay` | 8 | Не переторговывать |
| `MaxLossPercent` | 3% | Стоп-день |

## Запуск / стоп

- Старт: EA на график + Algo Trading  
- Стоп: снять EA или выключить Algo Trading  
- Открытая позиция при стопе не закрывается сама  

## Честно

Можно использовать для себя и тестировать.  
**Нельзя честно рекламировать как «гарантированно зарабатывает»** — такого EA не существует. Перед любыми деньгами других людей нужны свой бэктест, форвард и дисклеймер.
